## About

4th-year Software Engineering student at the University of Costa Rica, currently working as a **Test Process Development Intern at Teradyne** — building AI-based solutions for semiconductor test systems in the NPI group.

Selected as a **Databricks Student Fellow 2026**, one of 36 students chosen globally from over 5,000 applicants. The only student from UCR and the only woman from Central America in the cohort, alongside peers from MIT, Carnegie Mellon and UC Berkeley.

I build things across the stack — from Python automation pipelines and AI model benchmarks to full-stack web applications and systems-level C++ projects. I also founded **WebExpressCR**, a web agency serving Costa Rican small businesses.

Outside of code: Scrum Master by habit, math tutor, Ubuntu enthusiast.
